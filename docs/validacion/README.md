# Instrumentos de validación (EDT 4.5)

| Archivo | Uso |
|---|---|
| `protocolo_validacion.md` | Protocolo, tareas, clave de interpretación y cálculo de M-10, M-11 y M-12. |
| `formulario_utilidad.md` | Formulario impreso de utilidad (escala de 1 a 5). |
| `registro_sesiones.csv` | Una fila por participante, procedimiento (`mvp`/`onsv`) y tarea. `outcome` toma uno de estos valores: `correct`, `incorrect`, `abandoned`, `blocked` o `not_feasible`. Las horas van en ISO 8601. |
| `respuestas.csv` | Preguntas Q1 a Q6 (`correct` = 1/0) y utilidad U1 a U5 (`utility_score`). |

Los CSV están vacíos a propósito: los llena el equipo durante las sesiones reales.
