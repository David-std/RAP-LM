## Invariants (each one has a test)

1. **One run per request.** The active published run is resolved once; every value carries `run_id`.
2. **Full context.** Every result has `unit` (id, name, district), `period` (id, start, end, day type, band),
   `indicator_value`, `value_unit`, `risk_index`, `risk_level`, `availability`, `run_id`; `meta.legend`
   carries the threshold set (RF-07, M-02).
3. **No result ≠ zero.** A unit/period without a stored estimate is returned with `availability="no_result"`
   and null indicator, index and level (HU-21).
4. **No substitution.** Unknown `period_id`/`unit_id` → `404 UNKNOWN_PERIOD` / `UNKNOWN_UNIT`; never another
   period or unit.
5. **Comparability.** Cells and districts cannot be compared (`409 INCOMPATIBLE_COMPARISON`); items without
   result make `comparable=false` with a `reason` (HU-18).
6. **Scope.** `district_ids` accepts only UBIGEO `1501xx` (43 districts; Callao rejected with 422).
7. **Fail closed.** No published run → `503 NO_PUBLISHED_RUN`; database down → `503 DATABASE_UNAVAILABLE`.
   The API never falls back to demo data.

## Error schema

```json
{"error": {"code": "INVALID_PARAMETERS", "message": "Invalid query parameters.", "details": {"errors": []}}}
```

| HTTP | Codes |
|---|---|
| 404 | `UNKNOWN_PERIOD`, `UNKNOWN_UNIT` |
| 409 | `INCOMPATIBLE_COMPARISON` |
| 422 | `INVALID_PARAMETERS` |
| 503 | `NO_PUBLISHED_RUN`, `DATABASE_UNAVAILABLE` |

## Identifiers

* `unit_id`: `F{row}-C{col}` for 1 km cells (EPSG:32718 grid, row 1 = north), UBIGEO for districts.
* `period_id`: `{year}-{wd|we}-{HHHH}`, e.g. `2024-wd-1824` = 2024, weekdays, 18:00–24:00.
* Dates are ISO 8601, periods half-open `[start_date, end_date)`. GeoJSON is EPSG:4326.

### Fields added by dataset v1.2 and v1.3 (D-12)

- `risk[].breakdown.vehicle` (9 classes), `breakdown.service` (público, particular, carga, no identificado)
  and `breakdown.factor` (12 recorded factors, multi-label). Optional: absent for runs on older datasets.
- `explanations.context_profile`: `[indicator, value, percentile in Lima]` for the urban environment.
- `corridors[].properties.by_vehicle` and `by_factor`.

Recorded factors describe the record; they are never inputs of the network.

### `GET /api/v1/forecast`

Pronóstico anual de la red publicada, con horizontes encadenados (D-11, D-16). Parámetros: `unit_type` (`district` por defecto o `cell`),
`day_type` (`weekday` o `weekend`), `band` (0 a 3), `horizon_year` (opcional; por defecto el primer horizonte disponible). Devuelve `horizon_year`, `horizon_years`, `last_observed_year` y, ordenadas por
índice descendente, filas con `risk_index`, `risk_level`, `index_low`, `index_high` (rango del ensamble),
`previous_index` (año inmediatamente anterior al horizonte) y `expected_events` (solo distritos). `404 NO_FORECAST` si no hay datos para el horizonte y subperiodo solicitados. El rango del ensamble no es un intervalo de predicción calibrado.
